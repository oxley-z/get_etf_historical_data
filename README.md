# 获取基金最大回撤及修复情况

使用内置的 21 只预设基金列表，并默认分析最近 90 天的数据：

```python
python calc_fund_drawdown.py
```

| **参数**  | **短选项** | **类型** | **默认值**   | **说明**                         |
| --------- | ---------- | -------- | ------------ | -------------------------------- |
| `--start` | -          | `str`    | 90天前日期   | 统计起始日期，格式：`YYYY-MM-DD` |
| `--end`   | -          | `str`    | 当天日期     | 统计截止日期，格式：`YYYY-MM-DD` |
| `--funds` | -          | `list`   | 21只默认基金 | 待分析的基金代码列表，以空格隔开 |

分析特定历史时间段内的净值走势与回撤：

```python
python calc_fund_drawdown.py --start 2026-01-01 --end 2026-08-15
```

通过空格分隔，传入任意数量的场外基金代码：

```python
python calc_fund_drawdown.py --funds 002891 014002 012922 --start 2026-05-01
```
